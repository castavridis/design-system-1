# Assets

Source files for the pmndrs logo.

| File                | What it is                                                         |
| ------------------- | ------------------------------------------------------------------ |
| `logo_complete.svg` | The full mark, 600×600 (vector of `logo_complete.png`)             |
| `logo_idle.svg`     | The idle state, 600×600 (vector of `logo_idle.png`)                |
| `logo_complete.png` | The full mark, 600×600                                             |
| `logo_idle.png`     | The idle state, 600×600                                            |
| `logo_animated.svg` | Idle → complete in CSS, 0.73 s; still under reduced motion         |
| `logo_loading.svg`  | Loops idle → each corner → idle, 5.3 s; fades under reduced motion |
